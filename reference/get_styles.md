# Get list of styles from github.com/citation-style-language/styles

Get list of styles from github.com/citation-style-language/styles

## Usage

``` r
get_styles(...)
```

## Arguments

- ...:

  Named parameters passed on to
  [crul::HttpClient](https://docs.ropensci.org/crul/reference/HttpClient.html)

## Examples

``` r
if (FALSE) { # \dontrun{
x <- get_styles()
x[1:10]
} # }
```
